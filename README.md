# Blubber

Blubber is a self-hosted voice and text chat app for small communities – similar in scope to
Discord or TeamSpeak, but run on your own server.

## What it does

- **Voice channels** with low-latency audio
- **Screen sharing and camera** in voice channels
- **Text channels** with file and image attachments
- **End-to-end encrypted direct messages**
- **Roles and permissions** per server
- **Self-hosted:** each community runs its own server (Docker); one client can connect to several
  independent servers

## Platform

- Desktop client for Windows
- Server: Docker containers on a Linux host

## Status

Blubber is in private testing with a small group of users. The source code is not public yet;
this repository only describes the project.

## Third-party services

Blubber is an independently developed project. A GIF search based on the KLIPY API is planned as
an optional feature that each server operator can enable with their own API key. Blubber is not a
KLIPY product and is not endorsed by KLIPY.
